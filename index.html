How the pass is built

01

Pick a chain and an address

Each ecosystem uses its own address format and its own validator — a Solana address is never accepted where an EVM address is expected, or the reverse.

02

Chain-native security checks run

Data is pulled live from GoPlus Security's public API. The checks themselves differ by chain — Solana's mint/freeze authority model isn't force-fit into EVM's contract-function model.

03

A conservative verdict is formed

A single confirmed severe finding always means FAIL. Missing or unreadable data never quietly becomes a clean PASS — it's reported as insufficient data instead.

RiskPass is an independent screening aid built on free, public third-party data (GoPlus Security). It is not financial, legal, or investment advice, and a PASS result is not a guarantee of safety — it means no flags were found among the indicators actually checked, not that none exist. Always verify independently before signing any transaction or sending funds.

The address you submit is sent directly from your browser to GoPlus Security's API to run the check — RiskPass itself does not see, log, or store it, but GoPlus's own data practices apply on their end.
