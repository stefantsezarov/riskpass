How the pass is built

01

You submit an address

A token contract or a wallet address, on any supported EVM chain. Nothing is stored — the check runs live in your browser.

02

Public security data is queried

Contract behavior, holder concentration, and known-malicious-address records are pulled from GoPlus Security's free public API.

03

You get a plain-language pass

Raw flags are translated into a checklist and an overall verdict — PASS, CAUTION, or FAIL — with the full raw data available if you want it.

RiskPass is an independent screening aid built on free, public third-party data (GoPlus Security). It is not financial, legal, or investment advice, and a PASS result is not a guarantee of safety — it means no flags were found among the indicators checked, not that none exist. Always verify independently before signing any transaction or sending funds.

The address you submit is sent directly from your browser to GoPlus Security's API to run the check — RiskPass itself does not see, log, or store it, but GoPlus's own data practices apply on their end.

Data source: GoPlus Security API · api.gopluslabs.io
